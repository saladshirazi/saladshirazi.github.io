آموزش‌های متنی و گام‌به‌گام

قبل از هر چیز، این راهنماها را بخوانید؛ اکثر مشکلات اتصال با همین چند نکته حل می‌شود.

برای کسانی که اینترنتشان ضعیف است یا نمی‌توانند به کانفیگ‌ها متصل شوند:

  1. وارد تنظیمات شوید و روی «شبکه‌های تلفن‌همراه» بزنید.
  2. وارد بخش سیم‌کارت‌ها شوید.
  3. سیم‌کارتی که اینترنتش فعال است را انتخاب کنید.
  4. روی گزینه «نام‌های نقطه دسترسی» (Access Point Name / APN) بزنید.
  5. روی «+» یا «افزودن» بزنید تا یک APN جدید بسازید.
  6. فقط فیلدهای Name و APN را پر کنید (مثلاً هر دو را bahram بگذارید) و فیلد Proxy را خالی بگذارید.
  7. روی More و سپس Save بزنید تا ذخیره شود.
  8. APN جدید را انتخاب کرده و به اینترنت متصل شوید.
نکته: در تمام اپراتورها فیلد Proxy باید خالی بماند و گوشی از حالت رومینگ خارج شود.
  1. برای اندروید ۶ و ۷ (اجباری) و بالاتر (اختیاری) گزینه allowInsecure را در تنظیمات برنامه فعال کنید.
  2. روی آیکون + بالای صفحه بزنید.
  3. گزینه «Import config from clipboard» را انتخاب کنید.
  4. روی آیکون سه‌نقطه گوشه صفحه بزنید.
  5. گزینه «Update Subscription» را بزنید تا همه کانفیگ‌ها اضافه شوند.
  6. دوباره روی سه‌نقطه بزنید و «Real delay all configuration» را انتخاب کنید تا پینگ همه کانفیگ‌ها تست شود.
  7. گزینه «Sorting by test results» را بزنید تا بهترین‌ها بالای لیست بیایند.
  8. عدد سبزِ کوچک‌تر یعنی پینگ بهتر؛ روی آن کانفیگ بزنید و متصل شوید.

ساب‌های رایگان مهسا (قابل استفاده در v2rayNG، MahsaNG، Hiddify و Streisand):

.../mahsanet/MahsaFreeConfig/main/mci/sub_1.txt .../mahsanet/MahsaFreeConfig/main/mci/sub_2.txt .../mahsanet/MahsaFreeConfig/main/mtn/sub_1.txt .../mahsanet/MahsaFreeConfig/main/mtn/sub_2.txt
  1. لینک ساب را کپی کرده و روی «Add from clipboard» بزنید،
  2. یا از آیکون + گوشه بالای صفحه وارد «Manual Entry» شوید.
  3. یک نام دلخواه برای پروفایل تعیین کنید.
  4. لینک ساب را جای‌گذاری (Paste) کنید.
  5. بازه به‌روزرسانی خودکار را تعیین کنید (پیشنهاد: هر ۹۶ ساعت).
  6. روی Save بزنید.
  7. دکمه استارت برنامه را بزنید.
  8. روی Proxies بزنید تا لیست کانفیگ‌ها را ببینید.
  9. از منوی سه‌نقطه، گزینه «By Delay» را برای مرتب‌سازی بر اساس پینگ انتخاب کنید.
  10. روی دکمه صاعقه بزنید تا پینگ تست شود؛ حالت Auto خودکار بهترین را انتخاب می‌کند.

برای استفاده از Geph نیاز به ساخت یک حساب کاربری (نام‌کاربری و پسورد) دارید. این ابزار دارای سرورهای متعدد است و برای همهٔ اپراتورها قابل اتصال است.
